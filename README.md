Тэлеграм-бот для ўзаемадзеяння з ІІ-агентамі па генерацыі малюнкаў. Мае апрацоўшчыкі для:
 - загрузкі свайго малюнка і перадачы яго агенту з тэкставым прамптам (напрыклад: «выражы з гэтага малюнка нейкую дэталь, дадай новую дэталь»);
 - рэдагавання ўжо згенераванага малюнка ў патоку чата (праз механіку адказу на паведамленне) з дапамогай тэкставага апісання;
 - генеравання новага малюнка па тэкставым апісанні.

У цяперашнім варыянце бот узаемадзейнічае адразу з двума агентамі. Адзін агент здольны толькі генераваць малюнак па тэкставым апісанні. Другі можа прымаць малюнкі для аналізу і рэдагаваць іх. Гэта зроблена для эканоміі выдаткаў, бо другі агент каштуе даражэй незалежна ад таго, перадалі мы яму малюнак для перапрацоўкі ці папрасілі згенераваць новы па тэкставым апісанні. Бот аўтаматычна пераключаецца паміж імі ў залежнасці ад запускаемага апрацоўшчыка ў чаце.
