Телеграм бот для взаимодействия с ИИ-агентами по генерированию изображений. Имеет обработчики для: загрузки своего изображения и передачи его агенту с текстовым промптом (нпример: вырежи на этом изображени то то и то то, добавь это). Редактирования уже сгенерированного изображения.
В текущем варианте бот взаимодействует сразу с двумя агентами. Один агент способен только генерировать изображение по текстовому описанию. Второй может принимать изображения для анализа и редактировать его. Это сделано для экономии расходов т.к. второй агент стоит дороже вне зависимости от того, передали ли мы ему изображение для переработки или же попросили сгенерировать новое по текстовому описанию. Бот автоматически переключается между ними в зависимости от запускаемого обработчика в чате
